# SimonSays
 A web-based interactive memory game designed to challenge and improve cognitive recall. This project implements the classic "Simon Says" logic where players must     replicate a growing sequence of color flashes generated by the computer.  
 🕹️ Game Mechanics 
 The game follows a simple yet challenging loop that tests your short-term memory:
 Initialization: The game begins in a dormant state, prompting the user to "Press any key to start". 
 Sequence Generation: At the start of each level, the system adds one random color (Yellow, Green, Purple, or Blue) to the existing game sequence. 
 The Flash: The new color in the sequence is highlighted using the .flash CSS class, which briefly changes the button background to white. 
 User Interaction: Players must click the buttons in the exact order they appeared. Each user click triggers a distinct green flash (.userflash) to provide tactile    feedback. 
 Validation: The logic compares the user's input at each step against the stored gameSeq.
 Failure State: If the user clicks the wrong button, the background flashes red, the level is reset, and the final score is displayed. 
 🛠️ Technical Implementation
 📁 File Breakdown
 index.html:Defines the semantic structure of the game, including the main heading, level sub-heading, and the button containers organized into two rows. 
 stylesheet.css: Manages the visual layout using Flexbox for centering. It defines the dimensions for the .btn class (130px x 130px) and sets the specific RGBA and    RGB values for the four game colors. 
 app.js: Contains the core game engine, utilizing document.querySelector and addEventListener to manage game states, generate random indices for color selection, and  handle the asynchronous timing of flashes using setTimeout.  
 💻 Key Functions
 levelUp(): Resets the user's sequence, increments the level counter, updates the UI, and pushes a new random color into the game array. 
 checkAns(idx): The primary logic gate that determines if the user's current tap matches the game's sequence at that specific index. 
 reset(): Clears the gameSeq and userSeq arrays and sets the level back to zero, allowing for an immediate restart without refreshing the page.  
 🎨 UI DesignButtons: Large, rounded buttons (20% border-radius) with thick black borders for high visibility.
 Responsive Feedback: The body background shifts to red upon a loss and reverts to white after 150ms to signal the end of a session. 
 Typography: Uses center-aligned text and bold score displays to keep the player focused on the gameplay.
